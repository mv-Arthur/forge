# Вайрфреймы: сценарий «Готовые проекты» + «Построенные объекты»

> **Роль (для агента):** КАНОНИЧЕСКИЙ док по раскладке экранов и привязке элемент↔поле модели. Реализуя
> UI — источник ЗДЕСЬ. Модель полей — REDESIGN-TZ §1 / PRISMA-DRAFT; задачи вёрстки — BUILD-BACKLOG WP4/WP5/WP6.
> Легенда нотации (`[Field.x]`, `[CONV]`, §-ссылки) — ниже.

Низкодетальные ASCII-скетчи. Глобальный TopBar (экран 0) + пять экранов сценария, desktop и
mobile для каждого. Назначение — согласовать состав блоков и привязку каждого элемента к полю
модели, до вёрстки. У значимых элементов в скобках указан источник данных — поле из §1 ТЗ
(`Project.*`, `BuiltObject.*`, nested-сущности, обратные связи). `[CONV]` — конверсионный
элемент. Только поля, реально описанные в §1 (включая помеченные `+` — целевое состояние после
миграции).

Легенда полей:
- `Project.*` — §1.1; nested — §1.2 (`ProjectFloorPlan`/`Room`, `ProjectPlanningVariant`,
  `ProjectPackage`/`Include`, `ProjectOption`, `ProjectEngineering`, `ProjectStage`, `ProjectRelation`).
- `BuiltObject.*` — §1.3; nested — §1.4 (`BuiltObjectPhoto`/`stage`, `BuiltObjectMilestone`).
- `builtObjects` — обратная связь `Project ← BuiltObject.baseProjectSlug` (§1.5): «построен N раз».
- `[baseProjectSlug]` — FK объекта на его проект (§1.3, ряд `baseProjectSlug`; §1.5). В Prisma-дельте
  (§1.6) колонка называется `baseProjectId String?`, доступ к проекту — через relation `baseProject`;
  в скетчах ниже используется терминология §1-таблицы (`baseProjectSlug`), она резолвится в
  `baseProject.slug`. Обе записи означают одну и ту же связь «построен по проекту».
- `Setting.*` — глобальные значения (телефон **8-800**, мессенджеры TG/WA, ставка ипотеки, трасты,
  счётчики компании, ID Метрики).
- `Promo.*` — активная акция (§1.4): `oldPrice`/`discountLabel`/`deadline`.

Общие конверсионные инварианты (§4.1 P0):
- Телефон во всех CTA — это vanity-номер **8-800** (label из `[Setting]`, §4.1 P0#5), а не безликий
  глиф. Ниже он подписан как `[8-800]`, источник — `[Setting]`.
- Мессенджер-first: `[◇TG] [◇WA]` + callback присутствуют во всех ключевых CTA (§4.1 P0#5).
- Квиз-CTA «Рассчитать стоимость» живёт в глобальном TopBar (экран 0), на главной и в каталоге
  (§4.1 P0#3). В сценарных экранах ниже он приходит из шапки; продублирован в каталоге (экран 2).
- Избранное/сравнение — анонимно через localStorage, без аккаунта; ЛК лишь синхронизирует (P2).
  Кнопки `[♡ избранное]`/`[⇄ сравнить]` на карточке/детали не требуют авторизации.

## Экран 0. Глобальный TopBar / шапка (сквозной, все страницы)

Не входит в 5 сценарных экранов, но несёт три обязательства §4: квиз-CTA «в шапке», 8-800 и
мессенджеры «во всех ключевых CTA», глобальный вход в лид-воронку. Приведён, чтобы требования
§4.1 P0#3/#5 были прослеживаемы из скетчей.

### 0.1 Desktop

```
┌───────────────────────────────────────────────────────────────────────────┐
│ [лого]  Проекты  Построено  Комплектации  Отзывы  О компании               │  навигация
│                       [ Рассчитать стоимость ]   ☎ 8-800-XXX  [◇TG][◇WA]     │
│                         квиз-CTA [CONV]           [8-800][CONV] [Setting][CONV]│
└───────────────────────────────────────────────────────────────────────────┘
```

- Квиз-CTA «Подобрать/Рассчитать» `[CONV]` — глобальный вход в квиз «Подбор» (подбор-гибрид: критерии
  → 3-5 проектов + вилка цены → лид; не привязан к проекту, PODBOR-DESIGN), контакты из `[Setting]`
  (§4.1 P0#3 «в шапке»).
- Телефон `[8-800]` `[CONV]` — vanity-номер как явный label из `[Setting]`, кликабелен
  (`phone_number_click`), а не декоративный глиф (§4.1 P0#5).
- Мессенджеры `[◇TG][◇WA]` `[CONV]` в шапке наравне с телефоном, deep-link из `[Setting]`
  (§4.1 P0#5 «TG/WA в TopBar наравне с телефоном»).

### 0.2 Mobile

```
┌────────────────────┐
│ [лого]  ☎8-800 [≡] │  8-800 label [CONV][Setting]; меню — бургер
├────────────────────┤
│ [ Рассчитать ▸ ]   │  квиз-CTA [CONV] — под шапкой, всегда виден
└────────────────────┘
```

- На mobile 8-800 остаётся видимым label `[8-800]` `[CONV]` (не прячется в бургер), квиз-CTA —
  отдельной строкой под шапкой; мессенджеры — в бургер-меню и в FloatingContact.

- Трасты: «построен N раз» = `[builtObjects.length]`; «хит» = `[Project.featured]`.
- Мессенджер deep-link `[CONV]` — контакты и префилл-шаблон из `[Setting]`.

(онлайн-камера/менеджер/технадзор) прямо НАД CTA, реальные фото+планы. gwd — **два шаблона**: серийный
(цена «10,75 млн ₽» + акция-дедлайн + якорные табы Планировка/Фасады/**Что входит**/Отзывы) и
индивидуальный (без цены, одна CTA «Получить презентацию»); ТТХ бейджами под hero; sticky-CTA на mobile.

**Наша раскладка (desktop):** навбар с телефоном+мессенджером → крошки + H1 → первый экран 2 колонки:
ЛЕВО крупная галерея (рендеры+фото+планировки), ПРАВО конверсионный блок (цена «от X ₽» крупно + «в
ипотеку от Y ₽/мес» + плашка акции-дедлайна + CTA «Получить презентацию» + вторичная «Консультация» +
мессенджер-CTA) → строка ТТХ-бейджей → inline-переключатель «Построить из» (`ProjectMaterialVariant`,
пересчёт цены/пакетов) → якорные табы Планировка/Фасады/Что входит/Отзывы/Этапы → планы
этажей с площадями → триггеры доверия иконками → «Что входит» (комплектация) → отзывы/реализованные
объекты → финальная форма. Индивидуальные проекты — отдельный лендинг (ссылка-CTA), не режим страницы.
**Mobile (критично, у legacy сломано):** галерея на всю ширину → СРАЗУ цена+ипотека+CTA (не прятать
вниз) → ТТХ → планы → доверие; ОБЯЗАТЕЛЬНО **sticky-CTA снизу** + иконки звонка/мессенджера в шапке.

### Каталог — карточка и фильтры
**Факты:** legacy — фильтры-диапазоны над гридом + чипы-типоразмеры; карточка = фото + бейдж «Хит» +
иконки-характеристики 2×2 + крупная «Цена от». aps — тёмная тема, фото встык без рамок, подпись =
серия + иконки, БЕЗ цены (имиджево). gwd — двухколоночник: богатый сайдбар (инпуты от/до по площади и
стоимости + **чипы-пресеты** «до 200 м²/до 11 млн», технология/этажность/комнаты чипами) + карточки-
баннеры (название+характеристики поверх фото, метка типа, теги + **лайки со счётчиком**).

**Наша карточка:** крупное фото-баннер во всю ширину + нижний градиент; поверх снизу-слева название +
иконки-характеристики (площадь/спальни/санузлы/этажи); верх-левый угол промо-бейдж, низ-правый метка
типа/серия, верх-правый избранное+сравнение; под фото полоса: серые теги + «построен N раз»
(`builtObjects.length`) + бейдж «Хит»/featured (`Project.featured`) + **крупная контрастная
«Цена от: X ₽»** (в отличие от aps/gwd — цену показываем). Desktop: sticky-сайдбар
(инпуты+чипы-пресеты как gwd) + грид; над гридом счётчик + «Сортировать по». Mobile: тоггл «Показать
фильтр» (боттом-шит) + одноколоночный грид. Cookie — нижняя полоса, НЕ центр.

### Построенные дома `/works` (самый слабый наш экран)
**Факты:** legacy — `/map/` с десятками пинов (соц-доказательство масштаба) + детальная объекта с
«Параметрами» (сроки старт→финиш) + CTA «Записаться на просмотр объекта». aps — фото-галерея по
проектам + брендированные под-лендинги посёлков + VR-тур. gwd — портфолио + галерея фасадов с
бейджем-счётчиком фото.

**Наша раскладка `/works`:** sticky-шапка → крошки + H1 + счётчик («N домов») →
переключатель **[Сетка] [Карта]**. Карта: полноширинная интерактивная с пинами + синхронная лента
карточек (клик пин⇄карточка). Сетка: фильтры (слайдер площади + чипы материала) → карточки
2-3 кол. с крупным фото + **бейдж-счётчик «N фото»** + факты (м²/материал/срок) → промо VR/3D →
финальный CTA «Запишитесь на просмотр готового объекта».
**Детальная `/works/[slug]`:** 2 колонки (крупное фото + панель «Параметры»: площадь/материал/
этажность/посёлок+GPS/срок старт→финиш + CTA «Записаться на просмотр» + вторичная **«Хочу такой же
проект»→каталог**) → **фотохроника стройки** сеткой (фундамент→коробка→фасад→готово, лайтбокс, счётчик)
→ мини-карта с пином → блок «Проект этого дома» (кросс-продажа) + похожие объекты → форма.

### Главная — конверсия above-fold
**Факты:** gwd — **ряд из 4 trust-иконок с ЧИСЛАМИ** («Гарантия 50 лет», «технадзор по 300+ пунктам»,
«Поддержка 24/7») сразу под hero + 8-800 + личный кабинет. legacy — эмоциональный фото-фон (семья),
конфигуратор подбора above-fold, floating «Рассчитать/Экскурсия», «Акции» красным. aps — гео-оффер
числом «20 КМ ОТ МКАД» + CTA «Записаться на показ» + часы работы + Telegram-тост.

**Наша раскладка:** top-bar (лого+город+адрес; 8-800+телефон+«Заказать звонок» акцентом + иконки TG/WA)
→ меню (…/Акции акцентом/…+поиск+ЛК) → hero (фото реального дома с жизненным контекстом, H1 с конкретным
оффером/числом, одна доминантная CTA акцентом; sticky-кнопки «Рассчитать»/«Экскурсия» справа) → полоса
живого действия с часами («Открытый показ… с 10 до 19», карусель офферов) → **ряд из 4 trust-иконок с
числами** → мягкий конфигуратор подбора (soft-конверсия) → «Популярные проекты» (без табов; отдельная
ссылка-CTA на лендинг индивидуальных проектов) → мягкий мессенджер-виджет (без перекрытия).

**Принцип по всем экранам:** один акцентный цвет строго под CTA (aps жёлтый / gwd зелёный), **числовые
трасты вместо общих слов**, мессенджер+8-800 всегда доступны, sticky-CTA на mobile.
