# Архив документации ncottage CMS

Замороженные документы. Описывают завершённую работу первого поколения — сборку
CMS «под ключ» и последующий QA-аудит. **Не обновляются.** Актуальное направление
продукта — в [../REDESIGN-TZ.md](../REDESIGN-TZ.md).

Код на момент архивации ещё соответствует SPEC/ROADMAP/CONTENT-MODEL, но направление
дальше задаёт редизайн-ТЗ, а не эти документы.

- **SPEC.md** — техспека CMS первого поколения. Модель данных отгружена (`prisma/schema.prisma`).
- **ROADMAP.md** — план сборки по эпикам A–G/E. Выполнен. Новый роадмап — `REDESIGN-TZ §5 (WP0–WP8)`.
- **CONTENT-MODEL.md** — карта миграции www → CMS (эпик E). Миграция выполнена.
- **KICKOFF.md** — kickoff-промт сборки A–G (оперативный, отработан).
- **QA-AUDIT.md** — kickoff-промт QA-свипа. Его результат — `QA-DOSSIER.md`.
- **QA-DOSSIER.md** — закрытый аудит (87 находок). Тела находок в настоящем времени,
  но описывают УЖЕ ИСПРАВЛЕННЫЙ код — источник истины по статусу в шапке документа.
